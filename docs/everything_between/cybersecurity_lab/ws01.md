# Windows 10 User Workstation - WS01
## Create Virtual Machine
After downloading the ISO for Windows 10 Evaluation Edition (available [here](https://www.microsoft.com/en-gb/software-download/windows10)), create a new virtual machine in VMware Workstation Pro (File > New Virtual Machine), with the following settings:  

* Typical (Recommended) configuration  
* Installer disc image file: Windows 10 Evaluation Edition ISO   
* Virtual machine name: WS01  
* Location: desired location for VMHD files  
* Specify Disk Capacity options: accept defaults  
* Once machine is created, add the following line to the `.vmx` file for the VM (can be found in the location specified for the VMHD files):  
    `suspend.disabled = "TRUE"`  
* Disable the network adapter  
    *Enabling internet connectivity at this stage can cause problems with installation files*

## Operating System Installation
*Use default network adapter (NAT) during OS installation - change to custom VMnet once installation completed*  
Power on the virtual machine, click inside the monitor window and hit any key when prompted. Proceed with Windows installation using the following settings:  

* Time and currency format/Keyboard or input method: as desired  
* Click "I don't have a product key"  
* Windows 10 Pro
* Accept license  
* Custom installation  
* Accept default OS installation drive  
* Set language and keyboard settings as desired  
* Specify "I don't have internet" and confirm to continue with limited features  
* Set username, password and security questions/answers as desired  
* Decline all Windows features offered

## Post-installation Configuration
Once OS installation complete:  

* Install VMware Tools  
* Shutdown  
* Connect network adapter (right-click VM > Settings > Network Adapter > Connect at power on)  
* (optional but highly recommended) Take snapshot of fresh OS installation  
* Power on and install standard applications as required  
    *I installed Google Chrome as a bare minimum*  
* Shutdown   
* Change network adapter to custom VMnet 
* (optional but highly recommended) Take snapshot  
* Power on and rename machine. Reboot as required  
**!!! Make sure your DC is powered on before attempting the next steps !!!**  
* Search "join" in the Start menu, then click "Access work or School", then "Connect", and lastly "Join this device to a local Active Directory domain". Enter the domain name and use domain admin credentials when prompted. Set the administrator account type to "Administrator"  
* Reboot as required then shutdown  
* (optional but highly recommended) Take snapshot
