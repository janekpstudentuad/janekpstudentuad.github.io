# Windows Server 2022 Domain Controller - DC01
## Create Virtual Machine
After downloading the ISO for Windows Server 2022 Evaluation Edition (available [here](https://info.microsoft.com/ww-landing-windows-server-2022.html)), create a new virtual machine in VMware Workstation Pro (File > New Virtual Machine), with the following settings:  

* Typical (Recommended) configuration  
* Installer disc image file: Windows Server 2022 Evaluation Edition ISO  
* Windows product key: blank  
* Version of Windows to install: trivial - this will be set during installation  
* Personalize Windows: trivial - this will be set during installation  
* Virtual machine name: DC01  
* Location: desired location for VMHD files  
* Specify Disk Capacity options: accept defaults  
* Once virtual machine created in Workstation, remove floppy disk drive (right-click > Settings > highlight Floppy disk drive > Remove)  
    *This avoids issues with license files on reboot*

## Operating System Installation
*Use default network adapter (NAT) during OS installation - change to custom VMnet once installation completed*  
Power on the virtual machine, click inside the monitor window and hit any key when prompted. Proceed with Windows installation using the following settings:  

* Time and currency format/Keyboard or input method: as desired  
* "Install now"  
* Windows Server 2022 Standard Evaluation (Desktop Experience)  
    *"Desktop Experience" version is important if you want more than a command line interface!*
* Accept license  
* Custom installation  
* Accept default OS installation drive  
* Set administrator password as desired  

## Post-installation Configuration
Once OS installation complete:  

* Login with administrator credentials  
* (optional) Adjust system time if required  
* (optional) Adjust display scaling if required  
* Install VMware Tools (in Workstation Pro, VM > Install VMware Tools. Run setup from server CD drive; select Complete setup option)  
* Restart then shutdown  
* Change network adapter to custom VMnet (right-click VM > Settings > Network Adapter > Custom > select previously created custom VMnet adapter from dropdown menu)  
* (optional but highly recommended) Take snapshot of fresh OS installation  (right-click VM > Snapshot > Take snapshot)  
* Allocate static IP address (click on the network icon in the System Tray > Network & Internet Settings > Ethernet > Change adapter options. Right-click network adapter > Properties > Internet Protocol Version 4 > Properties. Use the following IP address > set desired IP and appropriate subnet mask)  
    *I used .10 from my custom VMnet network*  
* Rename machine (search Start menu for "name" > View your PC name. Rename this PC > rename as desired). Reboot as required  

## Active Directory Domain Services Installation and Configuration
### Installation
From Server Manager, click Manage > Add Roles and Features. Use the following settings:  

* Installation type: Role-based or feature-based installation  
* Destination server: accept default  
* Select server roles: Active Directory Domain Services (accept additional feature installation)  
* Select features: accept defaults  
* Allow automatic restarts if required  

### Configuration
From installation wizard, click "Promote this server to a domain controller" (once installation complete). Use the following settings:  

* Select "Add a new forest" and provide a name as required  
    *I used "homelab.local"*  
* Create password  
* Accept all other defaults

## Active Directory Certificate Services Installation and Configuration
### Installation
From Server Manager, click Manage > Add Roles and Features. Use the following settings:  

* Installation type: Role-based or feature-based installation  
* Destination server: accept default  
* Select server roles: Active Directory Certificate Services (accept additional feature installation)  
* Select features: accept defaults  
* Allow automatic restarts if required  

### Configuration
From installation wizard, click "Configure Active Directory Certificate Services on the destination server" (once installation complete). Use the following settings:  

* Credentials: accept default  
* Role Services: check Certification Authority  
* Accept all other defaults  

## DHCP Installation and Configuration
### Installation
From Server Manager, click Manage > Add Roles and Features. Use the following settings:  

* Installation type: Role-based or feature-based installation  
* Destination server: accept default  
* Select server roles: DHCP Server (accept additional feature installation)  
* Select features: accept defaults  
* Allow automatic restarts if required  
* Click "Complete DHCP configuration" (once installation complete) > Commit > Close  

### Configuration
From Server Manager, click Manage > Tools > DHCP. Then:  

* Expand server  
* Expand IPv4  
    *Required option will not appear on menu if IPv4 node has not been expanded*
* Right-click IPv4 > New Scope  
* Provide name as desired  
    *I used "Workstations"*  
* Provide start and end IP address for scope  
    *I used .100 - .200 from the custom VMnet network*  
* Leave all other defaults

## Finishing up
At this point, the initial setup for the domain controller is complete, and it is possible to create any domain users or groups you require in Active Directory. As a bare minimum, I did the following:  

* Create a new Organizational Unit (OU) called "Groups" and moved all the groups from the Users OU to the Groups OU  
* Create a single domain user to use with the workstations  

Finally, it would be a REALLY good idea if you shutdown the domain controller at this point and create a snapshot. It is optional, but will save you a lot of time and frustation in the future if you do.
