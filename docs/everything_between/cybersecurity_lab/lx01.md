# Ubuntu Desktop LTS - LX01
## Create Virtual Machine
After downloading the ISO for Ubuntu Desktop LTS (available [here](https://ubuntu.com/download/desktop)), create a new virtual machine in VMware Workstation Pro (File > New Virtual Machine), with the following settings:  

* Typical (Recommended) configuration  
* Installer disc image file: Ubuntu Desktop LTS ISO  
* Full name/User name/Password: as desired (trivial - will be set during OS installation)
* Virtual machine name: LX01  
* Location: desired location for VMHD files  
* Specify Disk Capacity options: increase size to 60GB    
## Operating System Installation
*Use default network adapter (NAT) during OS installation - replace with custom VMnet once installation completed*  
Power on the virtual machine and proceed with Ubuntu installation using the following settings:  

* Language/keyboard layout: as required  
* Accept all other defaults  
* Name: as desired  
* Computer name: LX01  
* Username/Password: as desired
* Accept all other defaults  
## Post OS Installation Configuration
Once the OS has finished installing:  

* Run the post-installation setup wizard:  

    * Skip Ubuntu Pro  
    * Don't share system data  
    * Don't install more applications  
* Apply updates (`sudo apt update && sudo apt full-upgrade -y`)

## Install DVWA
```
sudo git clone https://github.com/digininja/DVWA.git /var/www/html/dvwa
sudo cp /var/www/html/dvwa/config/config.inc.php.dist /var/www/html/dvwa/config/config.inc.php
sudo mysql -u root -p
CREATE DATABASE dvwa;
CREATE USER 'dvwa'@'localhost' IDENTIFIED BY '<password>';
GRANT ALL PRIVILEGES ON dvwa.* TO 'dvwa'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

* Update `/var/www/html/dvwa/config/config.inc.php` with password entered in SQL commands  
* Navigate to http://localhost/dvwa/setup.php and click "Create/Reset Database."
*Successful installation can be found at http://localhost/dvwa in an internet browser*
## Install and Configure Splunk
### Installation
* Obtain  the `wget` link to download the Splunk Universal Forwarder from [here](https://www.splunk.com/en_us/download/universal-forwarder.html)  
* Execute `wget` command  
* Shut down and change network adapter to custom VMnet network adapter  
*This is necessary for events to be sent to Splunk and to protect the deliberately vulnerable applications on the virtual machine from the public-facing internet*  
* Find adapter name with `ip a`  
* Choose a host address in the custom VMnet network that doesn't fall into the DHCP range from the DC  
*I chose .99*
* Overwrite contents of `/etc/netplan/50-cloud-init.yaml` with the following:  
```
network:
  version: 2
  ethernets:
    <hostOnlyAdapterName>:
      dhcp4: no
      addresses:
        - <lx01IpAddress>/24
      gateway4: <dcIpAddress>
      nameservers:
        addresses:
          - <dcIpAddress>
```
* Restart network service to apply configuration (`sudo netplan apply`)  
* Install and start Splunk Universal Forwarder (set admin credentials as the ones created during Splunk installation when prompted):  
```
sudo /opt/splunkforwarder/bin/splunk start --accept-license
```
### Configuration
* Create `/opt/splunkforwarder/etc/system/local/outputs.conf` with the following contents:  
```
[tcpout]
defaultGroup = default-autolb-group

[tcpout:default-autolb-group]
server = <splunkMachineIpAddress>:9997

[tcpout-server://<server = <splunkMachineIpAddress>:9997]
```
* Create `/opt/splunkforwarder/etc/system/local/inputs.conf` with the following contents:  
```
[default]
host = LX01

[monitor:///var/log/auth.log]
disabled = 0

[monitor:///var/log/syslog]
disabled = 0

[monitor:///var/log/messages]
disabled = 0
```
* Restart the Splunk Forwarder service (`sudo /opt/splunkforwarder/bin/splunk restart`)  
* Snapshot!
