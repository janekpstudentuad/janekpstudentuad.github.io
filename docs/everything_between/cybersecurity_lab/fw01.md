# pfSense - FW1
## Create Virtual Machine
After downloading the ISO for pfSense (available [here](https://www.pfsense.org/download/)), create a new virtual machine in VMware Workstation Pro (File > New Virtual Machine), with the following settings:  

* Typical (Recommended) configuration  
* Installer disc image file: pfSense ISO  
* Virtual machine name: FW01  
* Location: desired location for VMHD files   
* Change amount of RAM to 1GB   
* Add a second network adapter to connect to the custom VMnet network   
## Installation
* Power on the virtual machine  
* Set the WAN interface to the NAT network adapter  
* Set the LAN interface to the custom VMnet network adapter  
* Set the static IP address for the LAN network interface (choose an IP address not in the DHCP range set on the DC)  
*I used the .1 address in the custom VMnet network*  
* Set the start and end IP addresses of the DHCP range set on the DC  
* Install pfSense CE  
* Accept all other defaults  
* Snapshot!
## Reconfigure Endpoints for pfSense
### DC01
* Update default gateway and primary DNS server in network adapter IPv4 settings to pfSense LAN IP address  
* Navigate to https://pfsenseIpAddress and login with default credentials (admin:pfsense), run through initial setup, accepting all defaults and resetting admin password  
* Open DHCP (from Server Manager) > dc01.homelab.local > IPv4 > Scope > Scope Options > right-click white space > Configure Options  
* Tick 003 > add pfSense Ip Address in IP address > Add
### WS01 and WS02
* Update primary DNS server in network adapter IPv4 settings to DC IP address  
```
ipconfig /release
ipconfig /renew
```
* Snapshot! (for DC01, WS01, and WS02)
### LX01
* Update the `gateway4` address in the `sudo nano /etc/netplan/50-cloud-init.yaml` to the pfSense IP address  
* Apply the new configuration (`sudo netplan apply`)  
* Snapshot! (LX01 and FW01)
## ELK Stack Configuration
### Onion
* Confirm monitoring interface name (`nmcli con show`)
* Update the contents of `/opt/so/conf/suricata/suricata.yaml` as shown below. 
*`vi` required - enter "/af-packet" to find correct config setting, then "i" to enter editing mode. When done, press ESC, then ":wq" to save and exit*  
```
af-packet:
  - interface: <monitoringInterfaceName>
```
* Update the contents of `/opt/so/conf/zeek/node.cfg` with:  
```
[zeek]
type=worker
host=localhost
interface=<monitoringInterfaceName>
```
* Snapshot!
### FW01
* On DC01, navigate to pfSense admin console and login  
* Status > System Logs > Settings > Remote Logging Options > check the box for "Send log messages to remote syslog server" > enter onionIpAddress:514 in the first "Remote log servers" box > Save  
* Snapshot! (FW01)
